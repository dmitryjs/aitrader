# Trade Lens Cloud — первая рабочая сборка

Это исходный код облачного помощника и устанавливаемого расширения. Сервер подготовлен для Vercel. Он ещё не опубликован; Polza и Bybit с реальными ключами не проверены. Никаких реальных или виртуальных заявок эта версия не отправляет.

## Что получает пользователь

- Сайт с вопросом к модели и диагностикой подключений.
- Расширение Chrome: панель справа, Alt+Shift+L, выделение области Bybit через Alt+Shift+X, предварительный просмотр снимка и отправка по кнопке.
- Polza Chat Completions с моделью openai/gpt-6-astra. Модель проверяется по текущему каталогу перед запросом. Если ID отсутствует, показана ошибка; другой моделью не подменяется.
- Котировка BTC/USDT spot из Bybit public API.
- Баланс Bybit Demo с обязательной проверкой ключа только для чтения.
- Калькулятор размера длинной позиции без плеча: бюджет, максимальный сценарный убыток, стоп, комиссии и проскальзывание.
- Озвучивание ответа средствами браузера. Распознавание голоса пока не реализовано.

## Текущее препятствие публикации

Подключение Vercel видит профиль пользователя, но не возвращает доступных команд. Ранее запрос к команде аккаунта вернул 403 (неверная область доступа). Обход этого ограничения не выполнялся. Для публикации помощником нужно переподключить Vercel с доступом к нужной команде.

## Что делать пользователю

1. В управлении подключениями ChatGPT переподключить Vercel и предоставить доступ к своей команде / рабочему пространству. Не присылать токен Vercel в чат.
2. После создания проекта открыть в Vercel: Project → Settings → Environment Variables. Добавить значения из таблицы ниже. Секреты вводятся там, не в чате.
3. После сохранения переменных выполнить новый deploy / redeploy, затем открыть выданный URL. Для первичной проверки расширение не обязательно: сайт содержит чат, цены и калькулятор.
4. Для работы внутри Bybit установить расширение по инструкции ниже.

Локальный сервер и Node.js на компьютере пользователя не требуются. Пока не восстановлен доступ к Vercel, рабочего URL этой сборки нет. Старый URL trade-lens-design относится только к макету и не становится рабочим сервером автоматически.

## Переменные Vercel

| Имя | Значение | Тип |
| --- | --- | --- |
| POLZA_API_KEY | Ключ из кабинета Polza | Secret |
| POLZA_MODEL | openai/gpt-6-astra | Config |
| APP_ACCESS_TOKEN | Случайный отдельный код длиной минимум 32 символа, созданный менеджером паролей | Secret |
| BYBIT_DEMO_API_KEY | Ключ отдельного Demo Trading аккаунта, только чтение | Secret |
| BYBIT_DEMO_API_SECRET | Соответствующий секрет Demo Trading | Secret |

Для первого текстового запроса достаточно POLZA_API_KEY, POLZA_MODEL и APP_ACCESS_TOKEN. Котировки не требуют личного ключа Bybit. Без пары демоключей кнопка демобаланса показывает ошибку настройки, а не пример данных.

APP_ACCESS_TOKEN защищает личный помощник от посторонних запросов и расходов. Это не ключ Polza и не ключ Bybit. Он вводится в поле «Код доступа к помощнику» на сайте или в расширении. На сайте хранится только в памяти вкладки; в расширении — в локальном хранилище до выхода. API-ключи остаются в Vercel. После изменения любых переменных требуется redeploy.

## Установка расширения Chrome

1. Распаковать архив. Открыть chrome://extensions.
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку extension внутри комплекта.
4. Открыть вкладку https://www.bybit.com. Нажать значок Trade Lens.
5. В подключении указать корневой URL опубликованного проекта вида https://имя.vercel.app и APP_ACCESS_TOKEN. Разрешить доступ только к указанному серверу.
6. «Выделить область Bybit» → обвести элемент → проверить миниатюру → написать вопрос → «Спросить».

Расширение требует Chrome 116+ с Side Panel API. Яндекс Браузер и другие Chromium-браузеры отдельно не проверены. Рабочий домен сайта ограничен bybit.com / www.bybit.com. Если используется другой региональный домен, эта сборка не захватывает его и не пытается обойти ограничение.

Снимок устаревает через 2 минуты; после смены вкладки или навигации контекст сбрасывается. Полный кадр обрабатывается локально для обрезки; сервер получает только выбранный участок по нажатию «Спросить». Автоматического наблюдения нет. На мобильном телефоне расширение не поддерживается; облачный текстовый чат доступен через сайт.

## Приёмочная проверка после публикации

1. Неверный APP_ACCESS_TOKEN должен дать ошибку; без него личные API недоступны.
2. «Проверить модель» должен найти точный ID. Поддержка изображений по каталогу и реальный ответ на снимок — отдельные проверки.
3. «Обновить цену BTC» показывает источник и время ответа Bybit. При блокировке источника отображается ошибка; прокси-обход не предусмотрен.
4. «Получить демобаланс» показывает данные Demo и отклоняет ключ с разрешённой записью.
5. Текстовый вопрос получает ответ Polza. Вопрос с выделенным снимком относится к выбранной области.
6. Калькулятор даёт результат в рамках заданного бюджета и риска. Условия минимального лота и округление биржи пока не используются: это оценка, не готовая заявка.

Ожидаемая доступность источников из выбранного Vercel-региона fra1 ещё не проверена. Ошибка Bybit 403 или иное ограничение должна быть явно обработана без альтернативного прокси. Защита Vercel Deployment Protection может требовать дополнительной настройки доступа к своему серверу: её автоматическое отключение не выполняется.

## Для публикации инженером

Проект без зависимостей: Node.js 24.x, Vercel Functions в api/, статические файлы в public/, конфигурация vercel.json. Тип проекта Other; framework=null; outputDirectory=public. API доступен по /api/assistant. Сборка не требует Next.js.

Запуск проверок: npm test и npm run check.
Публикация — штатным импортом репозитория в Vercel либо Vercel API/CLI с подтверждённым доступом к нужной команде. Не добавлять секреты в репозиторий. .env.example содержит только названия переменных.

## Проверено и не проверено

11 автоматических тестов прошли: авторизация, происхождение и свежесть снимка, лимиты расчёта, HMAC-подпись, отказ при старых котировках, только демодомен и GET, запрет ключа с записью, отсутствие подмены модели, проверка vision, формат запроса Polza, отсутствие торгового маршрута. Синтаксис серверного и браузерного JavaScript проверен.

Тесты используют искусственные ответы API. Живые запросы с ключами, установка расширения, захват в браузере, озвучка, сборка и выполнение на Vercel ещё не проверены. Не выдавать этот архив за развёрнутый и проверенный live-продукт.

## Границы первой версии

Нет автоторговли, отправки демозаявок, непрерывного мониторинга, новостей, обучения модели, постоянного журнала или хранения разговоров на сервере. Переход к следующему этапу — только после приёмочных проверок. Vercel Functions обрабатывают запросы в пределах времени выполнения; постоянный торговый процесс потребует отдельно спроектированного исполнителя.

Финансовые числа рассчитываются кодом для сценария spot-long без плеча. Реальное исполнение стопа, дополнительные расходы и ликвидность могут изменить результат. Деньги Bybit не списываются по клику в этой сборке.
