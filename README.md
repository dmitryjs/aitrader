# Trade Lens 0.2.0

Личный помощник для BTC/USDT spot без плеча. Веб-интерфейс на Vercel и расширение Chrome. Заявки не отправляет.

## Состояние

Версия 0.1 была опубликована пользователем в Vercel. Скриншоты пользователя от 19.10.2026 подтверждают получение котировки Bybit, наличие openai/gpt-6-astra в каталоге Polza и текстовый ответ модели. Визуальный запрос и чтение демобаланса не подтверждены.

В версии 0.2 исправлена потеря привязки вкладки после загрузки страницы и добавлена оценка сценария сделки. 20 автоматических тестов прошли, включая регрессию привязки и расчёт результата с расходами. Тесты используют имитацию API и браузера. Работа нового расширения в пользовательском браузере и новый запрос оценки на опубликованном сервере требуют проверки.

## Обновление расширения

1. Распаковать архив и заменить файлы в ранее установленной папке extension.
2. На странице chrome://extensions нажать кнопку обновления карточки Trade Lens.
3. На вкладке Bybit нажать значок Trade Lens в панели браузера или Alt+Shift+L. Alt+Shift+X сразу запускает выделение.
4. Нажать «Выделить область Bybit», обвести участок и проверить миниатюру перед вопросом.

Если расширение загружается впервые: режим разработчика → «Загрузить распакованное расширение» → именно папка extension с manifest.json. Ввести URL своего проекта .vercel.app и APP_ACCESS_TOKEN. Открытие через меню боковых панелей может не выдавать activeTab: потребуется значок расширения или хоткей. Chrome 116+, Яндекс Браузер отдельно не проверен.

Старая версия расширения не обновляется от деплоя Vercel. Номер новой версии виден в заголовке: 0.2.0.

## Оценка сделки

Вкладка «Сделка»: бюджет, планируемый вход, стоп, цель, допустимый убыток, комиссия каждой стороны и запас на проскальзывание. «Подставить последнюю цену BTC» запрашивает API и заполняет ориентир входа. Комиссия не определяется автоматически: используется тариф пользователя. Проскальзывание — заданное пользователем изменение цены исполнения.

«Только расчёт риска» работает без цели. «Оценить сделку с Astra» требует цель выше входа, получает свежую котировку и считает количество BTC, расходы, убыток у стопа, результат у цели, отношение результата к риску и цену безубыточности. Числа считает серверный код. Модель получает эти расчёты и объясняет сценарий; при отказе модели расчёт сохраняется. Если котировка отсутствует или ответ Bybit старше 30 секунд, оценка блокируется. Время API — не время последней сделки; показанная цена не гарантирует цену исполнения.

Расчёт не проверяет минимальный лот, вероятность цели, свечные сигналы или стратегию. Это не рекомендация покупать и не готовая заявка. Реальный убыток при гэпе, недостатке ликвидности или других расходах может превысить сценарную оценку.

## Настройка Vercel

Импорт GitHub, Framework Other, root ./, конфигурация vercel.json. Сервер Node.js 24.x, api/assistant.js, интерфейс public/. Зависимостей нет.

Переменные окружения Production:

- POLZA_API_KEY — секрет из кабинета Polza.
- POLZA_MODEL — openai/gpt-6-astra.
- APP_ACCESS_TOKEN — отдельный случайный код минимум 32 символа.
- BYBIT_DEMO_API_KEY и BYBIT_DEMO_API_SECRET — необязательный отдельный Demo Trading ключ только для чтения, без вывода средств.

Секреты только в Vercel, не в репозитории или сообщениях. Изменение переменных требует redeploy. На сайте код доступа хранится в памяти вкладки, в расширении — локально до выхода. Баланс автоматически не передаётся модели. Текст вопроса, выбранный снимок и параметры оценки передаются в Polza только при соответствующем действии пользователя.

## Границы и защита

- Только bybit.com / www.bybit.com; только текущая разрешённая вкладка. Нет разрешения на все сайты.
- Снимок обрезается локально, отправляется по кнопке. Срок контекста 2 минуты; навигация и смена вкладки инвалидируют снимок.
- При навигации в пределах разрешённого origin привязка сохраняется, снимок сбрасывается. На другой origin привязка удаляется. Кнопка выделения восстанавливает привязку только на уже доступной активной вкладке Bybit.
- Код повторно проверяет вкладку и действительность выделения после захвата.
- Все API-действия требуют APP_ACCESS_TOKEN. Торгового API нет.
- Demo API: только GET, только api-demo.bybit.com, проверка readOnly до чтения кошелька. Wallet balance не равен доступным средствам.
- Нет непрерывного мониторинга, свечного анализа, новостей, обучения, дневного журнала, симулятора исполнения и голосового ввода. Есть браузерная озвучка ответа.
- Инструкции внутри страниц и снимков считаются недоверенными данными.

## Проверки

`npm test` — 20 тестов. `npm run check` — синтаксис API и расширения.

После обновления: версия 0.2.0 → выделение и миниатюра → ответ по снимку; «Сделка» → валидные параметры → числа и отдельное объяснение модели. Новая форма требует серверного маршрута review из того же обновления. Отсутствие демобаланса не мешает котировкам, снимкам и оценке сценария.
