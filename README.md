# Trade Lens 0.3.0

Наблюдение за разрешённой вкладкой Bybit, объяснения Astra и виртуальный торговый эксперимент. Реальные заявки не отправляются. Полные правила и ограничения эксперимента — STRATEGY.md.

## Что изменилось

- Режим «Наблюдение»: определяет BTC/USDT, ETH/USDT или SOL/USDT по адресу спотовой страницы; показывает распознанные названия кнопок, положение мыши и последнее нажатие на известный элемент.
- Не считывает пароли, значения полей или весь текст страницы. Названия элементов ограничены фиксированным словарём; они не являются командами для модели. Нажатие не считается подтверждением биржевого исполнения.
- Раз в 15 секунд получает цену и закрытые 15-минутные свечи через API. Вычисляет средние и диапазон движения. При потере вкладки наблюдение приостанавливается.
- Astra сама выдаёт короткую сводку после запуска, затем при новой закрытой свече или изменении направления. До 12 платных запросов за час за одну открытую сессию панели, с интервалом не меньше минуты. Перезапуск панели сбрасывает локальный счётчик; это не серверный лимит расходов. Сводки и озвучка отключаются флажками.
- Подсвечивает однозначно распознанную кнопку «Купить» или «Лимитный» по запросу. Не нажимает и не заполняет торговую форму. Это ограниченное сопровождение интерфейса, не универсальный визуальный агент.
- Стратегия BTC/USDT на часовых свечах, исторический тест, виртуальный счёт, подтверждение учебного входа, автоматический виртуальный выход по наблюдаемым данным, журнал и результат относительно цели +10 USDT.
- Оценка сделки вручную теперь поддерживает BTC/USDT, ETH/USDT и SOL/USDT. Новости, реальная торговля, обучение модели и голосовой ввод не добавлены.

## Обновление и запуск

1. Заменить файлы в установленной папке extension содержимым новой папки extension из архива. Обновить расширение на chrome://extensions.
2. Открыть https://www.bybit.com/trade/spot/BTC/USDT и нажать значок Trade Lens или Alt+Shift+L. Заголовок — 0.3.0.
3. При необходимости задать URL своего проекта Vercel и APP_ACCESS_TOKEN в «Подключении».
4. «Наблюдение» → «Включить наблюдение». Перемещение мыши внутри страницы отражается в панели. Сводка появляется без вопроса и снимка.
5. «Проверить стратегию на истории» → дождаться реального отчёта. Затем «Создать виртуальный счёт». При действующем сигнале станет доступно подтверждение учебной покупки.
6. «Скачать журнал и тест» сохраняет данные для анализа. Реальный счёт Bybit не используется.

Сначала требуется действие пользователя, дающее activeTab. Открытие панели через меню браузера само по себе может не дать доступ. Chrome 116+, Яндекс Браузер отдельно не проверен. Поддерживаются bybit.com / www.bybit.com, точные маршруты spot/BTC/USDT, spot/ETH/USDT и spot/SOL/USDT. Другие монеты, контракты и региональные домены не подменяются BTC.

Наблюдение работает только пока панель открыта. После остановки или ухода со страницы открытая виртуальная позиция не отслеживается; после перерыва >45 секунд она закрывается по первой полученной цене с записью о перерыве. Это ограниченная симуляция, не биржевой Demo Trading.

## Сервер

Vercel: Framework Other, root ./, Node.js 24.x, api/assistant.js, public/. Секреты только в Environment Variables, не в репозитории или чате:

- POLZA_API_KEY
- POLZA_MODEL=openai/gpt-6-astra
- APP_ACCESS_TOKEN — отдельный случайный код минимум 32 символа
- BYBIT_DEMO_API_KEY и BYBIT_DEMO_API_SECRET — необязательные демоключи только для чтения, без вывода средств; используются только кнопкой чтения демобаланса.

После изменения переменных нужен redeploy. Публикация сервера не обновляет распакованное расширение. Для эксперимента ключи Bybit не требуются: источники публичные, счёт виртуальный.

Все API-действия требуют APP_ACCESS_TOKEN. Рыночные источники фиксированы; символы ограничены списком BTCUSDT/ETHUSDT/SOLUSDT. При недоступных или старых данных вход блокируется. Числа рассчитывает код, LLM объясняет. Указания из страницы не могут разрешать сделки, менять лимиты или выполнять инструменты.

## Проверка

- Пользователь подтвердил в 0.2 работу снимков и вопросов; ранее скриншоты подтвердили котировку Bybit и ответ Astra.
- В 0.3 прошли 33 автоматические проверки с имитацией API/браузера и синтетическими свечами: прежние функции, защита вкладки, автоматическое наблюдение, отсутствие будущих данных в индикаторах, пропуски свечей, комиссии, устаревший сигнал, лимиты и виртуальное исполнение.
- Фактическая история Bybit в среде разработки не получена. Результат на реальной истории не заявляется. Его вычисляет опубликованный сервер после нажатия кнопки теста.
- Чтение мыши, подсветка и полный новый сценарий в пользовательском браузере ещё не проверены. Тесты не доказывают доходность стратегии.

`npm test` — тесты. `npm run check` — синтаксис. Браузерные модули extension/ копируются в public/ для веб-версии; веб-версия не читает вкладки или мышь.
